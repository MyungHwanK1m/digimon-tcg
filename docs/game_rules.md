# 📘 디지몬 카드 게임 룰 정리 (이 앱 기준)

> 공식 종합 규칙(Ver.4.3, 2026-09-18)을 바탕으로, **이 앱이 실제로 어떻게 처리하는지**를 함께 적었다.
> 항목마다 번호가 있으니, 알고 있는 룰과 다른 곳은 번호로 알려 주면 된다 (예: "4-3이 다르다").
>
> - ✅ = 공식 룰대로 처리
> - ⚠️ = 앱이 단순화했거나 아직 다름
> - 키워드(블로커 · 재밍 등)의 자세한 설명은 [keyword_glossary.md](keyword_glossary.md)

---

## 1. 덱 구성

| 번호 | 룰 | 앱 |
| :--- | :--- | :---: |
| 1-1 | 메인 덱은 **정확히 50장** | ✅ |
| 1-2 | 디지타마 덱은 **0 ~ 5장**, Lv.2 디지타마 카드만 | ✅ |
| 1-3 | 메인 덱에는 디지타마를 넣을 수 없다 | ✅ |
| 1-4 | 같은 카드 번호는 메인 · 디지타마 덱을 합쳐 **최대 4장** | ✅ |
| 1-5 | (공식 룰 아님) 덱 빌더의 "황금 비율" — Lv.3 12~14 / Lv.4 10~12 / Lv.5 8~10 / Lv.6~7 4~6 / 테이머·옵션 6~8 | 추천일 뿐, 어겨도 대전 가능 |

## 2. 카드 종류

| 번호 | 종류 | 설명 |
| :--- | :--- | :--- |
| 2-1 | **디지타마** (Lv.2) | 디지타마 덱에서 육성 에어리어로 부화. 위에 Lv.3을 진화시켜 키운다 |
| 2-2 | **디지몬** (Lv.3 ~ 7) | 등장 코스트를 내고 배틀 에어리어에 등장, 또는 진화 코스트를 내고 진화. DP로 배틀 |
| 2-3 | **테이머** | 등장 코스트를 내고 필드에 놓는다. 지속 효과 (예: 신태일 — [자신의 턴] 자신의 디지몬 전부 DP +1000) |
| 2-4 | **옵션** | 사용 코스트를 내고 [메인] 효과를 쓴 뒤 트래시. 자신과 같은 색의 디지몬 · 테이머가 필드에 있어야 쓸 수 있다 → ⚠️ 앱은 색 조건을 아직 확인하지 않음 |
| 2-5 | **진화원 효과** | 카드가 다른 디지몬 아래(진화원)에 깔려 있을 때 위의 디지몬이 얻는 효과 |
| 2-6 | **[시큐리티] 효과** | 시큐리티 체크로 공개됐을 때 발휘하는 효과 |

## 3. 게임 준비

| 번호 | 룰 | 앱 |
| :--- | :--- | :---: |
| 3-1 | 메인 덱 · 디지타마 덱을 각각 섞는다 | ✅ |
| 3-2 | 선공 · 후공을 정한다 (앱: 코인 토스) | ✅ |
| 3-3 | 메인 덱에서 **5장을 패로** 뽑는다 | ✅ |
| 3-4 | **멀리건**: 패가 마음에 안 들면 1번만, 5장을 덱에 되돌려 섞고 다시 5장 | ✅ 코인 토스 후 멀리건 화면 (상대 AI도 패를 보고 멀리건 판단) |
| 3-5 | 멀리건 **후에** 메인 덱 위에서 5장을 뒷면으로 **시큐리티**에 놓는다 | ✅ |
| 3-6 | 메모리 게이지는 **0**에서 시작 | ✅ (연습 모드는 매 턴 메모리 3으로 단순화) |

## 4. 턴 진행

| 번호 | 단계 | 룰 | 앱 |
| :--- | :--- | :--- | :---: |
| 4-1 | **① 액티브 페이즈** | 자신의 레스트(가로) 상태 카드를 전부 액티브(세로)로 | ✅ |
| 4-2 | **② 드로우 페이즈** | 1장 드로우. **선공 첫 턴은 드로우 없음** | ✅ |
| 4-3 | **③ 육성 페이즈** | 아래 중 **하나만** 하거나 아무것도 안 함: (a) 육성 에어리어가 비었으면 디지타마 1장 부화 (b) 육성 에어리어의 Lv.3 이상 디지몬을 배틀 에어리어로 이동 | ✅ |
| 4-4 | **④ 메인 페이즈** | 등장 · 진화 · 옵션 사용 · 테이머 등장 · 어택을 원하는 만큼, 원하는 순서로 | ✅ |
| 4-5 | 턴 종료 | 메모리가 **상대 쪽(1 이상)** 으로 넘어가면 그 처리가 끝난 즉시 턴 종료 | ✅ |
| 4-6 | 패스 | 메인 페이즈에 패스를 선언하면 메모리가 **상대 쪽 3**이 되고 턴 종료 | ✅ |
| 4-7 | 덱 아웃 | 드로우 페이즈에 덱이 0장이라 드로우할 수 없으면 **패배** | ✅ (상대 AI도 동일) |

## 5. 메모리

| 번호 | 룰 | 앱 |
| :--- | :--- | :---: |
| 5-1 | 메모리 게이지는 하나를 양쪽이 같이 쓴다. 내 쪽 0 ~ 10 / 상대 쪽 1 ~ 10 | ✅ |
| 5-2 | 코스트를 내면 그만큼 상대 쪽으로 이동. 내 쪽이 0 이상이면 계속 행동 가능 | ✅ |
| 5-3 | 상대 쪽으로 넘어간 칸 수 = 상대가 다음 턴에 쓸 수 있는 메모리 (예: 내가 -2에서 끝내면 상대는 2로 시작) | ✅ |
| 5-4 | 메모리는 10을 넘지 않는다. 남은 메모리보다 비싼 코스트도 낼 수 있고, 게이지는 상대 쪽 10에서 멈춘다 | ✅ |
| 5-5 | 카드 효과로 메모리를 얻거나 잃을 수 있다 (예: 해머 스파크 [메인] +1, [시큐리티] +2 / 블로커 디지몬 [어택 시] -2) | ✅ |

## 6. 등장 · 진화

| 번호 | 룰 | 앱 |
| :--- | :--- | :---: |
| 6-1 | **등장**: 패의 디지몬을 등장 코스트를 내고 배틀 에어리어에 놓는다. 등장한 턴에는 어택 불가 | ✅ |
| 6-2 | **진화**: 진화 조건(레벨 · 색)에 맞는 디지몬 위에 패의 디지몬을 진화 코스트를 내고 겹친다 | ✅ |
| 6-3 | 진화하면 **1장 드로우** (진화 보너스) | ✅ |
| 6-4 | 진화해도 레스트/액티브 상태는 그대로 유지된다. 그 턴에 등장한 디지몬이 아니면 진화 직후에도 어택 가능 | ✅ |
| 6-5 | 육성 에어리어에서도 진화할 수 있다. 육성 에어리어의 디지몬은 효과를 발휘하지 않는다 | ✅ |
| 6-6 | 육성 에어리어에서 배틀 에어리어로 옮긴 디지몬은 "등장"한 게 아니므로 그 턴에 바로 어택 가능 | ✅ |
| 6-7 | 배틀 에어리어에 놓을 수 있는 디지몬 수에는 **제한이 없다** | ✅ |
| 6-8 | 2색 진화 조건이 있는 카드 (예: 오메가몬 BT1-084 = Lv.6 레드 **또는** 블루에서 6) | ✅ 내장 카드는 카드 이미지 기준으로 확인 |

## 7. 어택 · 블록 · 배틀

| 번호 | 룰 | 앱 |
| :--- | :--- | :---: |
| 7-1 | 액티브 상태의 디지몬을 레스트시켜 어택. 대상은 **상대 플레이어** 또는 **레스트 상태인 상대 디지몬** | ✅ |
| 7-2 | 등장한 턴에는 어택 불가 (≪속공≫ 등 예외 키워드는 내장 카드에 없음) | ✅ |
| 7-3 | 선공 첫 턴에는 실질적으로 어택할 디지몬이 없다 | ✅ |
| 7-4 | **블록**: 어택당한 쪽은 액티브 상태의 ≪블로커≫ 디지몬을 레스트시켜 어택 대상을 그 디지몬으로 바꿀 수 있다 (선택) | ✅ 내가 막을지 · 어느 블로커로 막을지 직접 고름. 상대 AI는 유리할 때만 블록 |
| 7-5 | **배틀**: DP가 낮은 쪽이 소멸. 같으면 **둘 다** 소멸 | ✅ |
| 7-6 | **[어택 시]** 효과는 어택 선언 직후 발휘 | ✅ |
| 7-7 | 상대 디지몬과의 배틀에서 이겨도 시큐리티 체크는 하지 않는다 (≪관통≫ 제외) | ✅ |

## 8. 시큐리티 체크

| 번호 | 룰 | 앱 |
| :--- | :--- | :---: |
| 8-1 | 플레이어에게 어택하면 상대 시큐리티 **맨 위 1장**을 공개한다 (≪시큐리티 어택 +N≫이면 N장 더, 1장씩) | ✅ |
| 8-2 | 공개한 카드가 **디지몬**이면 그 DP로 배틀. 어택한 디지몬이 지거나 비기면 소멸. 공개된 카드는 결과와 상관없이 트래시 | ✅ |
| 8-3 | 공개한 카드가 **옵션**이면 [시큐리티] 효과를 발휘한 뒤 트래시 | ✅ |
| 8-4 | 공개한 카드가 **테이머**이면 [시큐리티] 효과("코스트를 지불하지 않고 등장")로 그 플레이어 필드에 등장 | ✅ ([시큐리티] 문구가 없는 카드는 그냥 트래시) |
| 8-5 | 체크 도중 어택한 디지몬이 필드를 떠나면 남은 체크는 하지 않는다 | ✅ |
| 8-6 | 시큐리티 디지몬 DP는 효과로 바뀔 수 있다 (예: 리키 [상대의 턴] +2000, 스타라이트 익스플로전 +7000) | ✅ |

## 9. 승패

| 번호 | 룰 | 앱 |
| :--- | :--- | :---: |
| 9-1 | 상대 시큐리티가 **0장**일 때 상대 플레이어에게 어택이 통하면(블록당하지 않으면) **승리** | ✅ |
| 9-2 | 단, 시큐리티 체크를 1장도 할 수 없는 디지몬(체크 매수 0)의 어택으로는 이길 수 없다 | ✅ |
| 9-3 | 드로우 페이즈에 덱이 0장이면 패배 (4-7) | ✅ |

## 10. 효과 처리 기본

| 번호 | 룰 | 앱 |
| :--- | :--- | :---: |
| 10-1 | **[자신의 턴]** 효과는 자신의 턴에만, **[상대의 턴]** 효과는 상대의 턴에만 적용 | ✅ (진화원 DP 보너스 포함) |
| 10-2 | **[턴에 1회]** 효과는 한 턴에 한 번만 발휘 | ✅ |
| 10-3 | "이 턴 동안" 효과는 그 턴이 끝나면 사라진다 | ✅ |
| 10-4 | "다음 상대의 턴 종료 시까지" 같은 기간 효과 | ✅ |
| 10-5 | DP가 효과로 **0 이하**가 되면 소멸 | ✅ |
| 10-6 | **≪퇴화 N≫**: 맨 위 카드를 N장까지 버린다. Lv.3이 되거나 진화원이 없으면 더 버릴 수 없다 | ✅ |
| 10-7 | 대상을 골라야 하는 효과 | ⚠️ 드래그로 대상을 고르는 카드 외에는 **가장 유리한 대상을 자동 선택** |
| 10-8 | "~할 수 있다"(선택) 효과 | ⚠️ 대부분 **항상 사용**으로 처리 |
| 10-9 | 동시에 여러 효과가 발휘될 때 순서 선택 | ⚠️ 정해진 순서로 처리 |

## 11. 이 앱에서 아직 다르거나 빠진 것

| 번호 | 내용 |
| :--- | :--- |
| 11-1 | 내장 120장 중 효과가 **문장만 있고 동작하지 않는** 카드: 장한솔(ST4-14) · 신태일 흑(ST5-14) · 매튜 퍼플(ST6-14) — 테이머를 레스트시키는 효과가 아직 없음 / 헤라클레스캅테리몬(ST4-13)의 ≪디지버스트≫ / 오메가몬(BT5-086)의 ≪진격≫ · 효과 내성 / 알포스브이드라몬(BT2-032) · 브이몬(BT2-021) 진화원 |
| 11-2 | 내장 120장 외의 카드(도감 약 4,400장)는 **효과 미구현** — ≪블로커≫ · ≪시큐리티 어택 +N≫ · 조건 없는 진화원 DP만 자동 적용 |
| 11-3 | 옵션 카드의 색 조건(2-4)을 아직 확인하지 않음 |
| 11-4 | 연습 모드(솔리테어)는 상대가 없으므로 매 턴 메모리 3으로 시작하고, 상대 시큐리티를 앞면으로 볼 수 있다 (실전 대련은 공식 룰) |
| 11-5 | 상대 AI는 옵션 카드를 [메인]으로 쓰지 않는다 (시큐리티에서 나온 옵션 효과는 정상 발휘) |
