## 1. 최근 작업 완료 내역 요약

### 1-1. 상대 AI 덱 선택 기능 구현
- **기초 덱 프리셋 6종 풀 지원**:
  - `ST-1` 가이아 레드 (워그레이몬 & 오메가몬)
  - `ST-2` 코퀴토스 블루 (메탈가루몬 & 오메가몬)
  - `ST-3` 헤븐즈 옐로우 (세라피몬 & 샤인그레이몬)
  - `ST-4` 기가 그린 (헤라클캅테리몬)
  - `ST-5` 머신 블랙 (파워드라몬 & 크레니엄몬)
  - `ST-6` 베놈 바이올렛 (베놈묘티스몬 & 벨제부몬)
- **커스텀/사용자 덱 지원**:
  - `🛠️ 내가 만든 덱`: 로컬에 저장된 커스텀 덱(`saved_decks.json`)
  - `🪞 미러전`: 현재 플레이어가 장착/빌딩 중인 덱과 동일한 덱
  - `🎲 자동 배정`: 플레이어 덱의 메인 색상 상성을 분석하여 카운터 덱 자동 매칭
- **UI 연동**:
  - 메인 로비 우측 상단 덱 설정 바에 **`👾 상대 AI 덱`** 콤보박스 및 `[⚔️ 이 상대로 대련 시작]` 추가
  - 인게임 플레이매트 컨트롤 바에 **`👾 상대 덱`** 선택기 및 `[🔄 재대전]` 즉시 리셋 버튼 배치
  - 상대 배틀 에어리어 헤더에 현재 대전 중인 상대 덱 명칭 실시간 표시 (`VS [덱 이름]`)

### 1-2. AI 룰 엔진 및 덱 초기화 유연화
- 플레이어가 어떤 커스텀 덱(10~50장)을 지정하더라도 AI가 해당 덱에서 적정 성장기(Lv.3)를 탐색하여 필드에 자동 배치
- 시큐리티 5장 및 초기 손패 5장이 선택된 상대 덱의 실제 카드들로 100% 구성되도록 엔진 로직 강화

## 3. 대련장 디자인: "공식 플레이매트 듀얼 필드"

> ⚠️ 처음 설계한 CYBER NEO 대련장(일체형 네온 매트 + 플로팅 인스펙터 + 와이드 핸드)은 **폐기**했습니다.
> 대련장은 **디지몬 카드 게임 공식 플레이매트 배치**를 기본으로 하고, 연출은 **유희왕 마스터 듀얼**을 참고합니다.
> CYBER NEO 에서 만든 공통 팔레트·컨트롤 스타일(`Themes/CyberNeo.xaml`)은 계속 사용합니다.

### 3-1. 화면 구성 (3단)

| 영역 | 폭 | 내용 |
| :--- | :--- | :--- |
| **좌측 설명 패널** | 290 | 🧭 지금 할 일(페이즈·대상 선택 상태별 안내) · 📖 턴 진행 5단계(현재 페이즈 강조) · 🖱️ 드래그 앤 드롭 조작법 · 🧠 메모리 규칙 · 🎮 빠른 메뉴 |
| **중앙 듀얼 필드** | 나머지 | 공식 플레이매트 배치 (아래 3-2) |
| **우측 카드 설명** | 350 | 카드 효과 프리뷰 · 필드 디지몬 DP/테이머/진화원 내역 · 전장 현황 · 로그 (덱 빌더와 같은 고정 사이드바) |

### 3-2. 중앙 듀얼 필드 (공식 플레이매트 배치)

```
 [상대 덱 선택 · 재대전]        [상대 손패 뒷면]          [VS 덱 이름 · AI · SECURITY 5]
┌ 상대 매트 (180° 거울 배치) ───────────────────────────────────────────────┐
│ TRASH │                 BATTLE AREA (슬롯 4칸)                  │ SECURITY │
│ DECK  │                                                          │ (세로 스택)│
└───────────────────────────────────────────────────────────────────────────┘
 TURN · 페이즈   ME ⓾⑨⑧…②①⓪①②…⑨⑩ AI  (메모리 마커가 슬라이드)     [TURN END]
┌ 내 매트 ──────────────────────────────────────────────────────────────────┐
│ SECURITY               │            BATTLE AREA (슬롯 4칸)        │ DECK  │
├ DIGI-EGG ┬ BREEDING    │            TAMER                          │ TRASH │
└──────────┴─────────────┴───────────────────────────────────────────┴───────┘
 [YOU · SECURITY 5]                 부채꼴 손패 (매트 가장자리를 살짝 덮음)
```

- **카드 존 슬롯**: 유희왕 몬스터 존처럼 빈 슬롯을 점선 + 카드 모양 각인으로 미리 그려 둔다. 카드가 놓이면 슬롯 자리를 그대로 차지한다.
- **레스트 표시**: 레스트(REST) 디지몬은 카드를 90° 눕힌다 (유희왕 수비 표시).
- **카드 뒷면**: 비공개 카드(상대 손패·덱·시큐리티, 내 덱·시큐리티)는 TCG 카드 뒷면 디자인으로 그린다. `Duel.Brush.CardBackArt`(메인 덱, 세로) · `Duel.Brush.CardBackArt.Sideways`(시큐리티, 가로) · `Duel.Brush.EggBackArt`(디지타마 덱). 실제 TCG 카드 뒷면 이미지 `data/images/_card_back.jpg`(메인 덱) · `_digitama_back.jpg`(디지타마 덱)가 있으면 앱 시작 시(`App.OnStartup`) 이 이미지로 교체하고, 없으면 벡터로 그린 뒷면을 쓴다.
- **메모리 게이지**: 공식 매트처럼 `10 … 1 · 0 · 1 … 10` 숫자 원형 칸. 현재 값 위치로 발광 마커가 미끄러지듯 이동한다.
- **플레이어 플레이트**: 유희왕 LP 자리(좌하단 = 나, 우상단 = 상대)에 아바타 링 + 시큐리티 남은 수를 크게 표시한다.
- **손패**: 부채꼴로 펼치고, 마우스를 올리면 똑바로 서며 들어 올려진다. **등장/진화/사용 버튼은 없애고 드래그 앤 드롭으로만 플레이**한다.
  - 손패 → 배틀 에어리어 빈 곳: 등장 · 테이머 · 옵션 발동
  - 손패 → 내 디지몬 위: 진화
  - 육성 디지몬 → 배틀 에어리어: 배틀 이동
  - 배틀 디지몬 → 상대 시큐리티 / 상대 레스트 디지몬: 공격

### 3-3. 궁극체(Lv.6) · 초궁극체(Lv.7) 강림 포효 컷인

- 카드를 그대로 보여 주지 않고, **카드 일러스트 부분만 잘라 화면 가득 띄운 뒤 포효 연출**을 재생한다.
  - 줌 펀치 → 천천히 다가오는 카메라, 포효 순간 카메라 흔들림, 카드 색 오라 + 회전 집중선, 충격파 3연발, 화면 플래시, "크아아아앙!!" 효과음 문자, 이름 슬라이드 인
- **영상 지원**: `data/cutins/{카드번호}.mp4` 또는 `data/cutins/{디지몬 이름}.mp4` (`.wmv`, `.mov` 도 가능)가 있으면 그 영상을 재생한다. 영상이 끝나거나 화면을 클릭하면 닫히고, 재생에 실패하면 일러스트 연출로 대체한다.
  - 예: `data/cutins/BT1-084.mp4`, `data/cutins/워그레이몬.mp4`
  - 공식 애니메이션 영상은 저작권이 있으므로 저장소에는 포함하지 않는다. 직접 준비한 영상만 넣을 것.

## 6. 플레이 테스트 후 조정 (2026-10-19)

- **대련 화면 정리**: 좌측 설명 패널(지금 할 일 · 턴 진행 순서 · 조작 방법 · 메모리 규칙 · 빠른 메뉴)과 우측 '전장 현황' 지표를 제거했다. 우측에는 카드 설명 · 필드 DP 내역 · 로그만 남긴다.
- **덱 빌딩 화면**: 대련 전용 패널을 숨기고 큰 카드 + 효과만 보여 주는 '카드 상세' 모드.
- **코인 토스**: 실전 대련(AI)이 화면에 처음 보일 때마다 동전을 던져 선공 / 후공을 정한다. 앞면(ME) = 플레이어 선공, 뒷면(AI) = 상대 선공.
  - 선공은 1턴째 드로우 없음. 상대 선공이면 `GoldfishEngine.GiveFirstTurnToOpponent()`가 AI 1턴(드로우 없음)을 진행하고, 후공 플레이어는 1턴째에도 1장 드로우한다.
  - 후공에서 멀리건하면 현재 손패 매수(6장)만큼 다시 뽑는다.
  - 연습(솔리테어) 모드는 항상 플레이어 선공.
- **메인 로비 = 게임 타이틀 화면**: 전면 키 아트(초궁극체 일러스트, 흐린 배경 + 선명한 메인 그림) 위에 로고와 세로 메뉴 3개(⚔️ 실전 대련 [AI] / 🛠️ 덱 빌딩 & 도감 / 🎯 연습 [솔리테어])만 둔다. 하단에 출전 덱 이름만 작게 표시.
  - 로비에서는 상단 헤더(로비 버튼 · 화면 설명 · 탭 3개)와 가이드/승인 바를 숨긴다. 다른 화면에서는 헤더의 [🏠 로비]로 돌아온다.
  - 로비의 출전 덱 플레이트(덱 칩 · 상대 AI 선택)는 제거. 덱은 덱 빌딩, 상대 덱은 대련 화면 좌측 상단에서 고른다.
  - 메뉴 버튼 스타일: `Lobby.MenuButton` (BorderBrush = 왼쪽 강조 바 색, 호버 시 오른쪽으로 밀리며 발광)
- **상대 턴 리플레이**: AI 턴은 엔진에서 한 번에 처리되므로, 엔진이 행동마다 `GameState.OpponentTurnEvents`(턴 시작 · 진화 · 등장 · 테이머 · 공격 선언 · 블록 · 내 시큐리티 오픈 결과 · 다이렉트 어택 · 턴 종료)를 남기고, UI가 화면 가운데 띠에서 카드 그림과 함께 한 장면씩(약 1.5초) 다시 보여 준다. 클릭 = 다음 장면, [모두 건너뛰기].
  - 상대 선공 첫 턴은 공격하지 않는다(실제 게임은 첫 턴에 필드 디지몬이 없으므로). 코인 토스 전에 미리 찍힌 '내 1턴 준비' 로그는 상대 선공일 때 지운다.
- **승리 / 패배 화면**: 게임이 끝나면 VICTORY(금색 · 플래시 · 회전 광선) / DEFEAT(붉게 가라앉는 타이틀)와 결과 이유 · 턴 수 · 남은 시큐리티를 보여 주고 [다시 하기] [필드 보기] [로비]를 제공한다. 상대 턴 리플레이가 끝난 뒤에 뜬다.
  - `data/cutins/victory.mp4`, `data/cutins/defeat.mp4` (.wmv / .mov) 가 있으면 배경 영상으로 재생.
- **AI 시작 필드 수정**: 실전 대련에서 AI가 Lv.3 디지몬 1장을 미리 깔고 시작하던 것을 없앴다. 양쪽 모두 빈 필드에서 시작한다.
  - AI에도 육성 페이즈를 추가: 육성 에어리어가 비면 디지타마 부화, Lv.3 이상이 자라 있으면 배틀 에어리어로 이동(이동한 턴에 공격 가능, 플레이어와 동일). 진화는 배틀 + 육성 에어리어 디지몬 모두 대상.
  - AI가 비싼 카드를 무리하게 내서 큰 메모리를 넘기지 않도록, 넘겨주는 메모리를 최대 3으로 제한 (`MaxAiMemoryHandOver`).
  - 상대 매트에 상대 BREEDING 칸 표시 (내 육성 존의 맞은편).
- **버그 수정 — 시큐리티 어택 시 게임 종료**: 로그 목록(`LstActionLogs`)이 엔진의 `List<string>`을 직접 바인딩하고 있어서, 엔진이 로그를 추가한 직후 레이아웃이 돌면(시큐리티 스크롤 위치를 맞추는 `UpdateLayout`) WPF가 ItemsControl 불일치 예외로 앱을 종료했다. 매번 로그 스냅샷을 바인딩하도록 수정.
  - 안전장치: 처리되지 않은 UI 예외는 실행 파일 옆 `crash_log.txt`에 기록하고 알림을 띄운 뒤 게임을 계속 진행한다 (`App.OnDispatcherUnhandledException`).
- **메모리 이동 수정**
  - 공식 룰대로 메모리 게이지는 0에서 시작: 실전 대련의 선공(나 / AI)은 첫 턴을 메모리 0으로 시작한다 (이전에는 3). 연습 모드는 매 턴 3 유지.
  - 턴 시작 테이머 보정을 플레이어 · AI 공통 함수(`ApplyStartOfTurnTamerMemory`)로 통일: 신태일 = 최소 3 보장, 매튜 = 장마다 +1 (카드 효과 텍스트 기준). 연습 모드에서 신태일이 +1로 잘못 계산되던 것도 수정.
  - 로그 · 리플레이에 '넘겨받은 메모리 → 테이머 효과 → 시작 메모리'를 분리 표시 (예: 넘겨받은 +3 · 매튜 효과 +1 → 시작 +4). 이전에는 보정 후 값을 '넘겨준 메모리'로 표시해서 숫자가 맞지 않아 보였다.
- **전체 카드 도감 (약 4,500장)**
  - DigimonCard.io API 형식 변경에 맞춰 동기화 재작성 (`search.php` → `search`, `cardnumber` → `id`, `maineffect` → `main_effect`). 이전 코드는 카드를 하나도 받지 못하고 있었다.
  - `getAllCards`로 세트 접두어(ST1 ~ ST24, BT1 ~ BT27, EX1 ~ EX14, P, LM, AD1, RB1)를 구한 뒤 세트별 `search?card={세트}-`로 상세 정보를 받는다.
  - API 요청 제한(1분 약 15회) 준수: 요청 간 1.2초, 남은 횟수가 적으면 쉼, 429 + Retry-After ≤ 60초면 대기 후 재시도, 그보다 길면 즉시 중단하고 받은 것까지 저장. 다시 누르면 등급까지 받아 둔 세트는 건너뛰고 이어받는다.
  - 내장 한글 카드 120장만 '효과 구현'(`StarterDecks.IsBuiltInCard`), API 카드는 '효과 미구현': 대전에서 DP · 코스트 · 진화 조건과 효과 텍스트 맨 앞의 기본 키워드(＜Blocker＞, ＜Security A. +N＞)만 적용.
  - 바인더: 60장씩 페이지, 효과 구현 카드 먼저 정렬, SET · RARITY(C / U / R / SR / SEC / P) · EFFECT 필터, 미구현 카드에 '⚠ 효과 미구현' / '⚠ 키워드만' 배지, 카드 상세에 안내.
  - 이미지는 화면에 보일 때만 받고(중복 · 실패 재시도 방지, 화면 갱신은 0.5초 묶음), 미리 받기는 효과 구현 카드만. AI 자동 완성 · 로비 일러스트도 효과 구현 카드만 사용.
