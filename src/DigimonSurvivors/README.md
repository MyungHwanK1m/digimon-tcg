# ⚔️ DIGIMON SURVIVORS : DIGITAL RUSH (디지몬 서바이버즈)

**뱀서류(Vampire Survivors-like / Bullet Heaven)** 액션 서바이벌과 **디지몬 세대 진화(Digivolution)**, 그리고 **공식 디지몬 TCG 카드 시스템**을 융합한 C# (.NET 8.0 WPF) 60 FPS 데스크톱 아케이드 게임입니다.

---

## 🎮 게임 개요 및 핵심 특징

1. **자동 공격 & 쾌속 생존 조작**
   - 플레이어는 **[WASD]** 또는 **[방향키]**로 이동과 회피에만 집중합니다.
   - 장착한 모든 디지몬 필살기 및 보조 무기는 쿨타임에 맞춰 적들을 자동으로 조준/발사합니다.

2. **디지몬 세대 진화 시스템 (Evolution Milestone)**
   - 경험치(데이터 비트)를 모아 레벨을 올리면 특정 레벨 구간마다 **세대 진화(Digivolution)** 이벤트가 발생합니다.
   - **Lv.5**: **성숙기 (Champion / Lv.4)** 진화 ➔ 기본 DP 상승 및 범위 공격 각성
   - **Lv.15**: **완전체 (Ultimate / Lv.5)** 진화 ➔ DP +70% 폭증 및 중화기/유도탄 각성
   - **Lv.25**: **궁극체 (Mega / Lv.6)** 진화 ➔ 결전기 개방 (가이아 포스 / 코큐토스 브레스 등)
   - **Lv.35**: **초궁극체 (Ultra / Lv.7 - 오메가몬)** ➔ 성검 '그레이 소드'로 무쌍 플레이!
   - 진화 시 **체력이 100% 전액 회복**되고 전용 진화 연출 컷신이 발동됩니다.

3. **디지몬 TCG 연계 레벨업 카드 선택지**
   - 레벨업 시 실제 디지몬 카드게임(TCG) 일러스트가 담긴 3장의 카드가 제시됩니다.
   - **디지몬 카드**: 진화 및 고유 필살기 습득
   - **테이머 카드**: 신태일(공격력 증폭), 매튜(이속/쿨감) 등 지속 패시브
   - **옵션 카드**: 섀도우 윙, 디지바이스(체력 재생), 자석 반경 증폭 등

4. **완벽한 정밀 누끼 & 2D 스킬 이펙트 디자인 시스템**
   - 모든 디지몬 캐릭터/보스 스프라이트의 외곽 및 날개/다리 사이 고립 배경 포켓을 완전 투명화(`Alpha = 0`) 처리.
   - 12종 고유 필살기 전용 고해상도 2D 투사체/참격/폭발 이펙트 스프라이트 내장 (`Assets/Skills/`).
   - 회전 각도 및 궤적에 따른 다이내믹 투사체 렌더링.

5. **자체 내장 레트로 아케이드 사운드 신시사이저**
   - 외부 사운드 파일 의존성 없이 C# 메모리 스트림 기반 실시간 PCM 사운드 신시사이저 내장 (발사음, 피격음, 레벨업 팡파르, 진화 폭발음, 보스 경보음 등).

| 스타터 | 속성/타입 | 주무기 | 진화 트리 |
